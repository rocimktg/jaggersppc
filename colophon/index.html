Colophon

How this site is built, and why it’s built that way.

Hand-written HTML across a handful of pages, one shared CSS file with the whole design-token system in custom properties, and about two kilobytes of vanilla JavaScript — all of it progressive enhancement. The page works with scripting disabled; the script only adds the rules drawing themselves in and the figures counting up. No framework, no build step, no dependencies.

Type. Playfair Display for display and pull quotes, Oswald for labels and chrome, EB Garamond for body copy. Loaded from Google Fonts with display: swap.

Palette. A warm apothecary set — aged-paper cream, near-black ink, and three spot colours: vermilion for results and figures, ochre for editorial furniture, sage for the quiet second voice. The distressed rules are tiled SVG strips, masked rather than drawn as borders.

Illustrations. Engraved-style plates set straight on the page stock with a multiply blend, so the white knocks out and the ink sits on the paper.
